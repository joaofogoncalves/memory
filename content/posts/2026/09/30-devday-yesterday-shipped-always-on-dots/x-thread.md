**Main post:**
DevDay yesterday shipped always-on Dots on GPT-6 Astra, each with its own cloud computer, that keep going after the chat closes. A planned GPT-6.1 Astra was held back after it missed the bar for staying within scope and authorization.

Custom Rules let you allow an action, require approval, or block it, and an auto-review checks anything that could affect an account or share information, with a password change left to you. OpenAI is working with Microsoft so specialist dots can be managed through the controls in Agent 365.

Reusable cloud environments keep an approved Codex setup available from a computer, a phone, or the cloud, and Codex Security Cloud can scan a GitHub repository on a schedule or as commits arrive, drop duplicate findings, and prepare fixes while the laptop is closed.

The Decisions API, in limited preview, uses a version of GPT-6 Luna for a question with a fixed set of answers and returns a pick for classifying an input, routing a request, or choosing the agent's next action.

A team adopting this is choosing which work continues when people are away, and which next step stays a small call because the allowed answers were written down first.
