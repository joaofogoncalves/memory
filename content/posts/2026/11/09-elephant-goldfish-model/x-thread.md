Thousands of Googlers use this plugin every day to ship production code. A deep-context agent, the elephant, drafts the spec. A goldfish agent then reads that draft with none of the earlier conversation.

The goldfish only sees the document and the source it points to. That is how it finds the assumptions the elephant already treated as settled.

Google open-sourced the workflow last month. The useful habit is giving the review to an agent that was not in the room when the design was written.
